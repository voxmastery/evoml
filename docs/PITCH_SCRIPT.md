# Pitch script (5:00, eight sections)

The narration used in the cartoon pitch video. Timings after a 7 % tempo
adjustment: 0:00, 0:33, 1:10, 1:52, 2:30, 3:12, 3:49, 4:21, end card 4:56.

1. **Hook.** Every trading model claims an edge. Almost none can prove it, and the few that work quietly decay within weeks. This is EvoML: a self-evolving prediction model that runs on a laptop, needs no AI API key, writes its own neural network from first principles, and ships with the one thing the industry never ships: an honest, pre-registered, audited scoreboard.
2. **The problem.** Short-horizon prediction markets are noisy, adversarial and non-stationary. Most models are trained once and left to rot; most results are backtests with no control arm. In fintech the same failure shows up in fraud, risk and pricing models. Decay is the default. Proof is the exception.
3. **What we built.** Thirty live Solana tokens, Jupiter prices every five seconds, DexScreener flow. Every five minutes: up, down or abstain, fifteen minutes out. Logged before the outcome exists, resolved against the real price, flat quotes voided, glitches winsorised. A random control runs on the same coins and windows.
4. **It evolves.** A genome: features, architecture, threshold, mutation rate, humility cap. A tournament every thirty minutes: champion, two mutants, an immigrant from the hall of fame. Succession only by more than one standard error. Genetic programming invents new genes; every generation goes in the lab notebook.
5. **First principles.** The network is ours: forward pass, hand-derived backprop, Adam, pruning, gradient-checked. Float32 for AVX2. Children inherit their parent's weights. Chronos-Bolt ingested and measured honestly: 51.5 % alone, a coin flip.
6. **Results.** 14.5 days, 562 resolved calls, 56.6 %, skill z 3.1. Random control 50.6 %. Beats it with z 2.4. Every pre-registered gate passed.
7. **Honest by design.** A statistical edge, not a money machine. 103 tests, journal, ledger, dashboard, all open. No wallet, no keys, no live trading.
8. **Why Razorpay.** Fintech runs on risk decisions under uncertainty and every model decays. The hard part is knowing, continuously and honestly, whether it still beats the baseline, and letting it rewrite itself when it does not. That loop is EvoML.
